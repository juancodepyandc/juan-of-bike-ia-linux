Aurora-Connect — Options

Bridge local L extension communique avec ton bridge Aurora via cette URL. Defaut : http://127.0.0.1:3001. Utilise l URL trycloudflare pour acceder a distance (mobile).
Permissions Aurora peut alors executer n importe quel JS sur la page courante. Tu peux desactiver en cas de doute. Permet a Aurora de prendre une capture du tab actif via tabs.captureVisibleTab. Ajoute un menu contextuel quand du texte est selectionne.
