## 2024-10-24 - ReactMarkdown Component Memoization Anti-pattern
**Learning:** In React apps rendering markdown, particularly for conversational interfaces that type-out text incrementally (like `CoworkOverlay.tsx`), re-creating the `components` prop object on every render is a huge performance killer. Even if you wrap the components with `useMemo`, it doesn't help if you include frequently changing dependencies like `turn.content` or callbacks that get re-created (like `onQuickPrompt`). `ReactMarkdown` uses this object for the entire tree, and referential instability forces a full unmount/remount or re-render of every DOM node in the markdown document every time a new character is added during the typewriter effect.
**Action:** Extract the `components` map completely outside the component if possible, or memoize it with an empty dependency array `[]`. If callbacks are needed inside the components, use the "latest-ref" pattern (`useRef` + `useEffect` to hold the latest callback without triggering `useMemo` recalculation) to maintain strict referential equality of the `components` object across all renders.
