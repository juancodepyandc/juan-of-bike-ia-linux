## 2026-10-12 - Prevent isolated generation split in 3D pipeline
**Learning:** The pipeline defaults to orchestrating scenes, parsing the prompt into multiple objects when possible. A user explicitly requesting a single base block without an assembly context had their subject split into disconnected meshes because the 3D intent mapper wasn't appending the proper flag to the pipeline configuration.
**Action:** When a user expresses intent for `referenceFraming === 'isolated_subject'` and `subjectKind !== 'assembly'`, we must proactively inject `--no-scene` into `auroraArgs` passed to `python-services/aurora_3d_pipeline.py`.
## 2023-11-20 - [ReactMarkdown Memoization Trap]
**Learning:** `ReactMarkdown` is computationally expensive to parse and render. If its parent component re-renders (e.g., due to typing in a chat input updating state), or if its `components` object is recreated on every render (due to an unstable dependency like a callback), it forces `ReactMarkdown` to unmount and remount all child nodes. This causes significant performance bottlenecks for long markdown responses.
**Action:** Always wrap components containing `ReactMarkdown` in `React.memo` (like `Bubble` in a chat interface). Stabilize callback props passed to these memoized components using `useCallback`. For the `components` object passed to `ReactMarkdown`, ensure its `useMemo` dependency array is strictly `[]`. If the `components` mapping requires dynamic callbacks, use the `useRef`/`useEffect` (latest-ref) pattern to invoke them without adding them to the dependency array.
